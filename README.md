# 全球资产估值观察室

公开指数、行业和黄金的估值观察面板。

网页地址为 https://zizhui.github.io/global-valuation-observatory/ 。

页面包含历史 PE、均值和正负一个总体标准差参考线，支持 3 / 5 / 8 年窗口，提供价格、市值和财报数据。首页默认显示收藏，收藏保存在当前浏览器。

页面发布的是数据快照，各项指标分别标明日期。数据更新后重新发布即可在远程查看。浏览页面无需启动本地电脑。

数据来自中证指数、国证指数、恒生指数公司、蛋卷基金、上海黄金交易所、Yahoo Finance 和东方财富。不同来源的口径和采样频率见指数详情。航运和油气当前采用中证官方月报，尚缺完整历史 PE。黄金不适用 PE。
